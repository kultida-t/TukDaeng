# TukDaeng Documentation Workspace

This repository is organized by documentation purpose so Product, UX, Dev, and QA can find the current source of truth quickly.

## Start Here

For Front Office work, start with:

1. [FrontOffice/DOCUMENT_VERSION.md](FrontOffice/DOCUMENT_VERSION.md)
2. [FrontOffice/README_MODULE_INDEX.md](FrontOffice/README_MODULE_INDEX.md)
3. [FrontOffice/TukDaeng_Master_Product_Definition.md](FrontOffice/TukDaeng_Master_Product_Definition.md)

| Folder | Purpose |

## Notes

- If a Front Office document conflicts with Figma or older documents, use the source-of-truth order in [FrontOffice/README_MODULE_INDEX.md](FrontOffice/README_MODULE_INDEX.md).
- Source input `.docx` files are kept separately in [SourceInputs](SourceInputs) so PRD decisions can be traced back to original requirement documents.
- Historical daily logs are not the source of truth; use them only to understand work history.
