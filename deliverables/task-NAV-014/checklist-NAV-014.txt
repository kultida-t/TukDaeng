NAV-014 Manual Review Checklist — Bottom Nav contrast เวลาพื้นหลังสว่าง (FO Flow)
ผู้ตรวจ: ผู้ใช้ (ตรวจหน้าจอจริงผ่านภาพสกรีนเทียบ) | ผล: ผ่าน หลังแก้ 3 รอบ

เคส 1: Dark Mode + เลื่อนรูปพื้นหลังสว่างมาทับเมนูล่าง  -> พบชื่อเมนู/ไอคอนมองไม่เห็น (บั๊กต้นฉบับ) แก้แล้ว ผ่าน
  ผลที่คาด: ชื่อเมนูและไอคอนที่ไม่ได้เลือกเห็นชัดบนพื้นหลังสว่าง
เคส 2: พื้นหลังแถบเมนู Dark Mode ไม่เข้มเกินไป ดูเทียบกับ Light Mode  -> รอบแรกทำพื้นหลังเข้มเกิน ถอนออกแล้ว ผ่าน
  ผลที่คาด: พื้นหลังแถบเมนูกลับเป็นแบบเดิมก่อนแก้ ปรับเฉพาะสีตัวอักษร/ไอคอน
เคส 3: Light Mode ใช้สีชื่อเมนู/ไอคอนเดิม (เทาเข้มตามธีม)  -> รอบกลางเข้าใจผิดเป็นขาว คืนแล้ว ผ่าน
เคส 4 (regression): เมนูที่เลือกอยู่ยังเป็นสีแดง + ตัวหนาเดิม, แถบเมนูยังเป็นสไตล์ Glass เดิมทั้งสองโหมด  -> ผ่าน

--- Follow-up (session ถัดมา): ดรอปพื้นหลังเมนูที่เลือกใน Dark Mode ---
เคส 5: Dark Mode ดรอปหลังเมนูที่เลือกเป็นขาวสว่างเกิน เด่นกว่าไอคอน/ชื่อสีแดง -> แก้แล้ว ผ่าน
  ผลที่คาด: ดรอปหลังเมนู active ไม่สว่างแย่งสีแดงของเมนูที่เลือก
เคส 6: Dark Mode + เลื่อนรูปพื้นหลังสว่าง (นาฬิกา) มาทับเมนูล่าง ดรอปยังสว่างตามพื้นหลัง -> พบว่าลด alpha สีขาวอย่างเดียวไม่พอ เพราะ backdrop blur ดึงความสว่างจากพื้นหลัง -> เปลี่ยนดรอปเป็น smoked glass สีดำจาง ผ่าน
เคส 7 (regression): Light Mode ดรอปหลังเมนูที่เลือกยังเป็นสีเข้มจางเดิม ไม่สว่าง/ไม่กลืนเกินไป -> ตรวจแล้วโอเค ไม่ปรับ
