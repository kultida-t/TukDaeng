# PROMPT: ซีรีส์วิดีโอสั้น "วิธีใช้แอป TukDaeng" (คลิปละ 1-3 นาที)

> ใช้เป็น master brief สำหรับผลิตคลิปสอนใช้งานแอป Univerza Tukdaeng
> **แนวทางการผลิต: AI ทำทั้ง pipeline — เขียนสคริปต์, จับ/อัดหน้าจอแอปจริง (adb/emulator อัตโนมัติ), สังเคราะห์เสียงพากย์ TTS, ตัดต่อด้วยโค้ด (ffmpeg/moviepy), เรนเดอร์ไฟล์สุดท้าย**
> **มนุษย์ทำเฉพาะ: ตรวจดูคลิป + สั่งแก้ไข/อนุมัติเท่านั้น (review gate ต่อ 1 คลิป)**
> (ห้ามให้ AI video gen วาด UI แอป — ต้องเป็นภาพ/วิดีโอหน้าจอจริงจาก `screenshots/user-manual/` หรืออัดใหม่จาก emulator)

## ข้อมูลแอปที่ต้องใส่ใน prompt ทุกครั้ง

- **ชื่อแอป:** Univerza Tukdaeng (ตึกแดง) — แพลตฟอร์มซื้อขาย จัดแสดง และคอมมูนิตี้นาฬิกา
- **ดาวน์โหลด:** Google Play — https://play.google.com/store/apps/details?id=com.univerza.tukdaeng (มี iOS ด้วย)
- **จุดขายหลัก:** สำรวจนาฬิกาได้โดยไม่ต้องสมัคร (Guest mode) · โพสต์ขาย/โชว์คอลเลกชัน · เสนอราคา-ต่อรองในแชท · Watch Alert แจ้งเตือนเมื่อมีเรือนที่ตามหา · กระดานข่าว/บทความนาฬิกา
- **มุมมองผู้ใช้ 5 แบบ:** Guest (ยังไม่ล็อกอิน) / Member / Owner (เจ้าของรายการ) / Buyer (ผู้เสนอราคา) / Seller (ผู้รับข้อเสนอ)
- **โทนแบรนด์:** แดง #e50914 · กรมท่า #08172e · ทอง #c5a059 · ฟอนต์ Prompt / Sarabun

## กลุ่มเป้าหมาย
คนที่สนใจนาฬิกาทุกระดับ — นักสะสม, คนอยากซื้อเรือนแรก, คนอยากขาย/ฝากขาย, คนที่ชอบพูดคุยเรื่องนาฬิกาในคอมมูนิตี้

## โทนเสียงและสไตล์ (บังคับทุกคลิป)
- พูดเป็นกันเอง เหมือนเพื่อนที่รู้จักนาฬิกามาแนะนำ — ไม่ขายของแรง ไม่อุทานเสียงดัง
- ประโยคสั้น ชัดเจน บอก "แตะตรงไหน → เกิดอะไร" ตรงๆ
- เสียงพากย์ไทย TTS ความเร็วปานกลาง (~130-150 คำ/นาที) มีจังหวะหยุดให้ตามดูจอ — เลือกเสียงที่ฟังเป็นธรรมชาติ ไม่ใส่อารมณ์เกิน
- เพลงประกอบเบาๆ lo-fi/chill ระดับ -20dB ใต้เสียงพากย์ ไม่แย่งซีน (ใช้ไฟล์ royalty-free ในแผนก — mix ด้วย ffmpeg)
- ซับไตเติลไทยตลอดคลิป (คนดูโซเชียลส่วนใหญ่ปิดเสียง) — burn-in จาก timestamp ของ TTS ตัวหนังสือขาวขอบดำ หรือแถบแดงตึกแดง
- ขนาด 9:16 (1080×1920) สำหรับ Reels/TikTok/Shorts — ถ้าทำ YouTube ปกติทำเวอร์ชัน 16:9 เพิ่ม
- visual cue (วงกลม/ลูกศร/ซูมจุดที่แตะ) วาดด้วย overlay ใน ffmpeg/moviepy ตามตำแหน่งที่ระบุใน shot list

## โครงสร้างบังคับของทุกคลิป

```
[0:00-0:05] HOOK      — คำถาม/ปัญหาที่คนกลุ่มเป้าหมายเจอจริง 1 ประโยค
[0:05-0:10] CONTEXT   — "ในแอปตึกแดงทำได้แบบนี้" + ภาพหน้าจอแรก
[0:10-จบ]   STEP 1-3  — ทีละขั้น สั้นๆ แตะอะไร→เห็นอะไร (ซูม/วงกลมจุดที่แตะ)
[สุดท้าย 8-10 วิ] CTA — "โหลดได้เลยที่ Play Store / App Store ชื่อ TukDaeng"
                        + "สงสัยตรงไหนคอมเมนต์ถามได้เลย เดี๋ยวมาตอบ"
```

กติกาเพิ่มเติม:
- 1 คลิปสอนได้แค่ 1 flow หลัก (ไม่เกิน 3 ขั้นตอนใหญ่) — ถ้า flow ยาวให้ตัดเฉพาะ core path แล้วบอกว่า "รายละเอียดอื่นดูในคลิปถัดไป"
- ทุกครั้งที่แตะปุ่มให้มี visual cue (วงกลม/ลูกศร/ซูมเข้า) ราว 0.5 วิ
- ปิดท้ายด้วย end card: โลโก้ + ปุ่มดาวน์โหลด + ชื่อคลิปถัดไปในซีรีส์
- ห้ามโชว์ข้อมูลส่วนตัวจริง (อีเมล/เบอร์/ชื่อเต็มของคนอื่น) — ใช้บัญชีทดสอบหรือ blur

## คลิปแรกที่ต้องผลิต — INTRO "แอปตึกแดงคืออะไร" (ภาพรวม/ขายงาน ไม่เกิน 3 นาที)

> **คลิปนี้คือ deliverable แรกของโครงการ** — เอาไว้แนะนำ/เสนอขายแอป ยังไม่สอนใช้งานเชิงลึก
> แยกจากคลิปสอนใช้ (EP1-10) ตรงที่: โฟกัส "ทำไมต้องมีแอปนี้" ไม่ใช่ "กดตรงไหน"

โครงสร้างของคลิป INTRO (≤180 วิ):

```
[0:00-0:08]  HOOK     — pain point กลุ่มนาฬิกา เช่น "หาที่ซื้อขายนาฬิกาที่ไว้ใจได้ยากมั้ย?"
[0:08-0:25]  WHAT     — TukDaeng คืออะไร: แพลตฟอร์มซื้อขาย + จัดแสดง + คอมมูนิตี้นาฬิกา
                        (montage: splash → feed → asset detail)
[0:25-0:45]  WHO      — ใครใช้: นักสะสม / คนอยากขาย / คนอยากซื้อ / คนอยากคุยเรื่องนาฬิกา
                        + จุดขายเปิด: สำรวจได้ทันทีไม่ต้องสมัคร (Guest mode)
[0:45-2:15]  FEATURE TOUR — เดินเมนูหลัก 5 อัน (ฟีด/แชท/กระดานข่าว/แจ้งเตือน/โปรไฟล์)
                        + ลูกเล่นเด่น 4-5 อย่าง: ค้นหา+ตัวกรองครบ, โพสต์ขายหรือโชว์ (SALE/SHOW),
                        เสนอราคาต่อรองในแชท, Watch Alert เฝ้าหาเรือนที่อยากได้, โปรไฟล์นักสะสม
[2:15-2:45]  WHY      — สรุป 2-3 จุดว่าตอบโจทย์ยังไง (ครบวงจรในที่เดียว / เริ่มง่าย / community)
[2:45-3:00]  CTA      — "โหลด TukDaeng ได้เลย" + ปุ่ม store + "ติดตามคลิปสอนใช้แบบละเอียดต่อได้เลย"
```

สิ่งที่ต้องมีในคลิป INTRO:
- ภาพรวม navigation: bottom nav 5 เมนู (ฟีด · แชท · กระดานข่าว · แจ้งเตือน · โปรไฟล์) ให้เห็นชัด
- montage เร็วของฟีเจอร์เด่น — ไม่ต้องสอนทีละขั้น แค่ flash ให้เห็นว่า "มีสิ่งนี้"
- ป้าย SALE/SHOW ควรโชว์เพราะสื่อ "ซื้อขาย + โชว์" ได้ในภาพเดียว
- โทนเดียวกับซีรีส์ (เป็นกันเอง ไม่อุทาน) แต่จังหวะเร็วกว่าคลิปสอน — คลิปนี้คือ pitch ไม่ใช่ tutorial

## Pipeline ผลิตต่อ 1 คลิป (AI ทำทั้งหมด — มนุษย์ตรวจอย่างเดียว)

```
STAGE 1 SCRIPT     AI เขียนสคริปต์พากย์ + shot list (ใช้ PROMPT แม่แบบด้านล่าง)
                   output: scripts/video-guides/EP<n>-script.md (ไทม์โค้ด + ข้อความพากย์ + ซับ)
STAGE 2 ASSET      AI เตรียมภาพ/วิดีโอหน้าจอจริงตาม shot list
                   - static: ใช้ screenshots/user-manual/<ไฟล์> ที่มีอยู่
                   - motion: อัดจออัตโนมัติผ่าน emulator (adb shell screenrecord / screencap
                     + input tap ตามพิกัด — workflow เดียวกับตอนทำคู่มือ)
                   output: assets/video-guides/EP<n>/
STAGE 3 VOICE      TTS ไทยจากสคริปต์ → EP<n>-voice.wav + timestamp ต่อประโยค (สำหรับซับ)
STAGE 4 COMPOSE    ตัดต่อด้วยโค้ด (ffmpeg/moviepy): วางภาพ/วิดีโอตามไทม์โค้ด,
                   transition, ซูม/วงกลมจุดแตะ, burn-in ซับ, mix เพลง, end card
                   output: dist/video-guides/EP<n>-draft.mp4 (9:16, 1080x1920)
STAGE 5 REVIEW GATE   มนุษย์ดู draft → สั่งแก้ หรือ อนุมัติ
                      (แก้ = AI ปรับสคริปต์/asset/ไทม์มิงแล้วเรนเดอร์ใหม่)
STAGE 6 SHIP       EP<n>-final.mp4 + caption/แฮชแท็กที่ AI ร่างไว้ รอโพสต์
```

กฎ pipeline:
- ทุก stage ต่อ 1 คลิปต้องเรนเดอร์ซ้ำได้ (script/asset แยกเก็บต่อ EP — แก้ EP เดียวไม่กระทบคลิปอื่น)
- คลิป pilot = INTRO (ภาพรวมแอป) ทำก่อนเพื่อล็อก template/โทน — ใช้ภาพนิ่งที่มีอยู่ ไม่ต้องรอระบบอัดจอ แล้วคลิปอื่น reuse ระบบเดิม
- ถ้า stage ใดอัตโนมัติไม่ได้จริง (เช่น TTS เสียงไม่เป็นธรรมชาติ) ให้ flag ให้มนุษย์ตัดสินใจ ไม่ฝืนผลิตของแย่

## ตัวอย่างสคริปต์ต้นแบบ — EP.3 ค้นหา+ตัวกรอง (~90 วิ)

```
[HOOK 0:00-0:05] ภาพ: feed การ์ดนาฬิกาเลื่อนเร็ว
"อยากได้เรือนที่ใช่ ไม่ต้องเลื่อนหาให้เมื่อย — ตึกแดงมีตัวกรองครบเลย"

[CONTEXT 0:05-0:10] ภาพ: ช่องค้นหาบนฟีด (วงกลมที่ช่องค้นหา)
"แตะช่องค้นหาด้านบน แล้วพิมพ์ชื่อแบรนด์หรือรุ่นที่อยากได้"

[STEP 1 0:10-0:25] ภาพ: พิมพ์ "Rolex" → หน้าผลลัพธ์มีจำนวนผล
"เช่น พิมพ์ Rolex กดค้นหา — แอปจะโชว์ผลพร้อมบอกจำนวนเลยว่าเจอกี่เรือน"

[STEP 2 0:25-0:55] ภาพ: แผ่นตัวกรอง → เลือกแบรนด์ → ช่องรุ่นเหลือเฉพาะของแบรนด์นั้น → ป้าย Rolex ใต้ช่องค้น
"อยากละเอียดกว่านั้น แตะปุ่มตัวกรอง — เลือกได้ทั้งแบรนด์ รุ่น ช่วงราคา ปี สภาพ
จุดที่ชอบคือ เลือกแบรนด์ปุ๊บ ช่องรุ่นจะเหลือเฉพาะรุ่นของแบรนด์นั้นให้เลือกต่อ
ไม่ต้องเดาเอง ใช้กี่เงื่อนไขก็เห็นเป็นป้ายใต้ช่องค้นหาชัดเจน"

[STEP 3 0:55-1:15] ภาพ: เมนูเรียงลำดับ → เลือก "ใหม่ล่าสุด" → ไอคอนนาฬิกา (ซูม)
"เรียงผลได้ตามใจ — ราคาถูกสุดก่อน หรือเอาของเข้าใหม่ล่าสุด
```

## ข้อแนะนำเพิ่มเติม (นอกเหนือที่ขอ)

1. **ทำ Hook + CTA เป็นบังคับทุกคลิป** — โครงสร้าง Step-by-step + CTA ที่ให้มาดีแล้ว แนะนำเพิ่ม HOOK 5 วิแรก (คำถามที่คนกลุ่มนาฬิกาเจอจริง เช่น "เจอเรือนที่ชอบแต่แพงไป ทำไงดี?") เพราะคลิปสั้นตัดสินกันที่ 3 วิแรก
2. **ซับไตเติลตลอดคลิป** — กลุ่มเป้าหมายดูบนโซเชียลส่วนใหญ่ปิดเสียง สคริปต์พากย์ควรใช้เป็นซับได้เลย
3. **ใช้ภาพ/วิดีโอหน้าจอจริงเท่านั้น** — คลิปสอนใช้แอปที่ AI วาด UI ขึ้นมาจะทำให้คนทำตามไม่ได้และเสียความน่าเชื่อถือ; โปรเจกต์มี workflow จับภาพ emulator + ภาพจริง 170 ไฟล์อยู่แล้ว
4. **ทำคลิป pilot (INTRO ภาพรวมแอป) ก่อน 1 ตัว** — ใช้ล็อก template, โทนพากย์ TTS, สไตล์ cue/ซับ/end card ให้ผู้ใช้อนุมัติ แล้วค่อยยิง EP ที่เหลือด้วยระบบเดิม — ลดเวลาแก้ย้อนทั้งซีรีส์ (เมื่อถึงซีรีส์สอนใช้ EP5 เสนอราคาและ EP6 ลงขายคือคลิปสำคัญสุด ทำยาวเต็ม 3 นาทีได้)
5. **EP5 (เสนอราคา) และ EP6 (ลงขาย) คือคลิปสำคัญสุด** — เป็น flow ที่สร้างรายได้/ดึงผู้ขาย ควรทำก่อนและทำยาวเต็ม 3 นาทีได้
6. **ทำ caption โพสต์แยกต่อคลิป** — AI ร่างสรุป 3 ขั้นเป็นข้อความ + hashtag (#ตึกแดง #TukDaeng #นาฬิกามือสอง #ซื้อขายนาฬิกา) + ลิงก์โหลด ให้มนุษย์ตรวจพร้อมคลิป
7. **ปักคอมเมนต์ลิงก์ดาวน์โหลด** ทุกคลิป และทำ Playlist "สอนใช้ TukDaeng" เรียง EP0→EP10
8. **อย่าโชว์ข้อมูลส่วนตัวจริงในคลิป** — ใช้บัญชีทดสอบ/blur อีเมล ชื่อ เบอร์ ของผู้ใช้อื่นเสมอ (กฎนี้ใช้กับ asset ที่ AI จับใหม่ด้วย)
