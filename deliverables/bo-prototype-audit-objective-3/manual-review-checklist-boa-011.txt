BOA-011 — Sidebar Structure Options (8 checks)
== ขั้นตอนตรวจทุกรายการ
เปิด sidebar เทียบแต่ละตัวเลือกและกฎประกอบกับหน้าจอจริง → ตรวจทุก viewport (390, 768, 1280, 1440px)
== Checklist
01 ตรวจ sidebar 3 ทางเลือกที่ออกแบบ เทียบ mental model, usage frequency, workflow adjacency, permission และ submenu density — PASS
02 ผู้ใช้เลือก Option B — Workflow + Data Domains แบ่งเป็น งานประจำ / ข้อมูลและข้อมูลเชิงลึก / บริการและกำกับดูแล — PASS
03 Option B กำหนด Market Data, Market Demand, Option Master อยู่กลุ่มข้อมูลและข้อมูลเชิงลึก และ Account Deletion อยู่กลุ่มบริการและกำกับดูแล — PASS
04 เสนอใช้ชื่อ Market Overview แทน Dashboard ใต้ Market Data ลดความสับสนกับ Dashboard หลัก — PASS
05 Permission visibility — สิทธิ์ none ไม่แสดงเมนู, limited แสดงเฉพาะ submenu ที่เข้าถึงได้, route/API ยังตรวจสิทธิ์ — PASS
06 Cross-module active-state rule — หน้าปลายทางเป็นเจ้าของเมนู active ขณะที่ Back ยังกลับบริบทต้นทาง — PASS
07 แยก quick wins, product decisions และการเปลี่ยนที่กระทบ protected navigation ส่งต่อ BOA-013–BOA-015 — PASS
08 Manual QA ผ่านครบทุก viewport ไม่มีไฟล์หรือ protected screen ถูกแก้ — PASS
