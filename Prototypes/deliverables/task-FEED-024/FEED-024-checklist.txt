เคส 3: Archive / Pin to profile — ผ่าน (ปรับตาม feedback รอบ 8 — Archive ของจริง)
- Archive: flag archived + archivedAt → โพสต์หายจาก feed ทันที + toast "Post archived"
- Settings มีแถว "Archive" (icon history + count) ระหว่าง Wish List / Favorites
- หน้า Archive แสดง grid tile เหมือน Saved + ข้อความ "Only you can see posts you've archived"; empty state "No archived posts"
- แตะ tile → เปิด Archive viewer (feed-style cards title "Archive") → เมนู ... บนการ์ดมี "Unarchive" → โพสต์กลับเข้า feed + หน้า Archive ว่าง
- Pin to profile: memory-only flag + toast; label พลิกเป็น Unpin เมื่อเปิดเมนูซ้ำ

เคส 4: Turn off commenting — ผ่าน
toggle post.noComments → ปุ่ม comment หายจากการ์ด; label พลิกเป็น Turn on commenting

เคส 5: Edit — ผ่าน (ปรับตาม feedback รอบ 3 — Edit info เหมือนหน้า Add)
เลือก Edit → เปิด composer หน้า "Edit info" (Cancel / Done แทน Share) preload ข้อมูลโพสต์:
- media เดิมแสดงเป็น thumbs (clip มี dur badge) + tile "+" เพิ่มรูป/คลิปผ่าน picker "Add photos or clips" (Done = ยืนยันรูปที่เพิ่ม, < = ยกเลิกคืนค่าเดิม)
- กดค้างลาก thumb สลับตำแหน่งได้ (ไม่มี hint text ตาม feedback รอบ 4)
- ลบรูปด้วย × ได้ แต่กันไม่ให้เหลือ 0 — toast "Post needs at least 1 photo or clip"
- เพิ่มเกิน 10 ชิ้นถูกบล็อก — toast "You can add up to 10 photos or clips"
- แก้ caption / location / price / Watch details / Condition / More options (audience, commenting) ได้
- Done อัปเดตโพสต์เดิมใน POSTS (ไม่สร้างโพสต์ใหม่) + re-render ทุก surface + toast "Post updated"
- Cancel → confirm "Discard changes?" ทิ้งการแก้ไข โพสต์เดิมไม่เปลี่ยน

เคส 7: Delete — ผ่าน

เคส 8: หน้า Detail — ผ่าน (feedback รอบ 4)
- title "Detail" จัดกลางเหมือนหน้าอื่น (เพิ่ม spacer ซ้ายใน detail-head variant หลัก)
- ชื่อโพสต์ซ่อนส่วนที่เป็น N/A ("rolex N/A" → "rolex"); ถ้าไม่มี specs เลย fallback เป็น caption
- Reference ที่ไม่มีข้อมูลแสดง "Ref. -" (เดิม "Ref. N/A"); ในลิสต์ WATCH SPECIFICATIONS ยังแสดง N/A เหมือนเดิม
- มี section "Price & Data Source" เสมอเมื่อโพสต์มีรายละเอียด — ไม่มีราคาแสดง N/A (Asking Price / Estimated Market Price / Last Price Update = N/A, Data Source = TukDaeng Market Data)
- Descriptions = field description จริง (p.desc) — ไม่ใช่สำเนา caption; ถ้าไม่ได้กรอกแสดง "-"
- Watch details pane (ทั้งหน้า Add และ Edit) เพิ่มฟิลด์ "Description" เป็น textarea รองรับข้อความยาวกว่าฟิลด์อื่น
- Edit จากหน้า Detail: composer ถูก detail layer บัง (z-index) — แก้โดยปิด detail ตอนเปิด edit แล้วเปิดกลับหลัง Done/Cancel พร้อมเนื้อหาล่าสุด
