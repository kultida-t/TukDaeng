ผู้ตรวจ: ผู้ใช้ | ผล: รอยืนยัน

เคส 1: เมนู ... โพสต์ตัวเอง — ผ่าน (automated) + ปรับตาม feedback รอบ 2
โพสต์ seller = mycollection (CP_ME) กด ... → bottom sheet การ์ดเดียว 6 เมนู:
Save / Archive / Turn off commenting / Edit / Pin to profile / Delete(แดง)
ตัดออกตามสั่ง: preview card, เพลง, QR code, Shared/Share, Hide like and view counts, Create reel, Adjust preview — ไม่มีใน DOM

เคส 2: Regression โพสต์คนอื่น — ผ่าน
โพสต์ seller อื่นกด ... → เมนูเดิม Add to favorites / Not interested / Report เหมือนเดิมทุกประการ

เคส 3: Save — ผ่าน
toggle saved → sync ปุ่ม bookmark บนการ์ด + toast "Saved" / "Removed from your saved"

เคส 4: Archive / Pin to profile — ผ่าน
memory-only flag + toast; label พลิกเป็น Unarchive / Unpin เมื่อเปิดเมนูซ้ำ

เคส 5: Turn off commenting — ผ่าน
toggle post.noComments → ปุ่ม comment หายจากการ์ด; label พลิกเป็น Turn on commenting

เคส 6: Edit — ผ่าน (ปรับตาม feedback รอบ 3 — Edit info เหมือนหน้า Add)
เลือก Edit → เปิด composer หน้า "Edit info" (Cancel / Done แทน Share) preload ข้อมูลโพสต์:
- media เดิมแสดงเป็น thumbs (clip มี dur badge) + tile "+" เพิ่มรูป/คลิปผ่าน picker "Add photos or clips" (Done = ยืนยันรูปที่เพิ่ม, < = ยกเลิกคืนค่าเดิม)
- กดค้างลาก thumb สลับตำแหน่งได้ (ไม่มี hint text ตาม feedback รอบ 4)
- ลบรูปด้วย × ได้ แต่กันไม่ให้เหลือ 0 — toast "Post needs at least 1 photo or clip"
- เพิ่มเกิน 10 ชิ้นถูกบล็อก — toast "You can add up to 10 photos or clips"
- แก้ caption / location / price / Watch details / Condition / More options (audience, commenting) ได้
- Done อัปเดตโพสต์เดิมใน POSTS (ไม่สร้างโพสต์ใหม่) + re-render ทุก surface + toast "Post updated"
- Cancel → confirm "Discard changes?" ทิ้งการแก้ไข โพสต์เดิมไม่เปลี่ยน

เคส 7: เมนูจากหน้า Detail — ผ่าน
ปุ่ม ... (pm-btn) บนหน้า detail ของโพสต์ตัวเองเปิดเมนูชุดเดียวกัน

เคส 8: Delete — ผ่าน
confirm dialog "Delete post?" → ลบออกจาก POSTS + ลบการ์ดจาก feed/viewer + ปิด detail ถ้าเปิดอยู่ + toast "Post deleted"

เคส 9: หน้า Detail — ผ่าน (feedback รอบ 4)
- title "Detail" จัดกลางเหมือนหน้าอื่น (เพิ่ม spacer ซ้ายใน detail-head variant หลัก)
- ชื่อโพสต์ซ่อนส่วนที่เป็น N/A ("rolex N/A" → "rolex"); ถ้าไม่มี specs เลย fallback เป็น caption
- Reference ที่ไม่มีข้อมูลแสดง "Ref. -" (เดิม "Ref. N/A"); ในลิสต์ WATCH SPECIFICATIONS ยังแสดง N/A เหมือนเดิม
- Descriptions = caption ของโพสต์ (captionFull) ไม่ใช้ field desc แยกอีกต่อไป

เคส 10: More options ใน create flow — ผ่าน (feedback รอบ 2)
เอา toggle "Hide like and view counts" ออกจาก pane More options เหลือ Turn off commenting + audience Everyone/Followers only

เคส 11: Light theme — ผ่าน
เมนู render ถูกทั้ง dark/light
