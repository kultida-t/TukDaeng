เคส 2: กด "more" แล้ว toggle ปรากฏ — ผ่าน

เคส 3: เปิด/พับ spec เหมือนเดิม — ผ่าน
  กด "Tap for details" → spec กาง + label เปลี่ยน "Hide details"
  กดซ้ำ → spec พับกลับ label กลับ "Tap for details"

เคส 3.5: แตะ caption ที่กางอยู่ → ย่อกลับเหมือน IG — ผ่าน

  และ "Tap for details" หายไปเหมือนตอนก่อนกด more
  (ถ้า spec เปิดอยู่ จะพับปิดไปด้วย กลับสภาพเดิมเป๊ะ)

เคส 4: แท็บ Following / Favorites — ผ่าน

เคส 5: โพสต์ที่ไม่มี price/specs — ผ่าน
