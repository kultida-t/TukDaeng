เคส 2: หน้าเลือก Theme — ผ่าน (automated)

  Sensitive content / Watch Alerts; มี 2 ตัวเลือก Light mode (ไอคอน sun) /
  Dark mode (ไอคอน moon) พร้อมคำอธิบายสั้น และเครื่องหมายถูกบนโหมดที่ใช้อยู่

เคส 3: Apply ทันทีทั้งจอ — ผ่าน (automated)
  แตะ Light mode → .screen[data-theme] เปลี่ยนเป็น light ทันที (ทุก CSS var

  ทั้งจอ — ใช้ token เดียวกับ dark/light ที่มีอยู่แล้ว ไม่เพิ่มชุดสีใหม่

เคส 4: จำค่า (persistence) — ผ่าน (automated)

  ค่าเริ่มต้น (ยังไม่เคยเลือก) = dark เหมือนเดิม

เคส 5: sync กับปุ่ม toggle ใน review sidebar — ผ่าน (automated)

  Theme mode ใน Settings แสดงค่าตามจริงเมื่อเปิดใหม่
