เคส 1: เมนู ... การ์ดเดียวคั่นเส้นตาม IG — ผ่าน (automated)
  จากภาพ IG ที่ผู้ใช้ส่ง: แถวทั้งหมดอยู่การ์ดเดียวคั่นด้วยเส้นบาง —
  Report(แดง) / Block / About this account / Copy profile URL /
  Share this profile + Cancel การ์ดแยก (Restrict/See shared activity/
  Hide your story/QR code ไม่ใส่ — เคยตัดไว้ตั้งแต่ PROFILE-001/003);
  แถว Block ผูก data-u = username ของโปรไฟล์นั้น; ตอน blocked แถวนี้
  เปลี่ยนเป็น "Unblock" ตาม IG

เคส 2: Block confirm sheet — ผ่าน (automated)
  กด Block → bottom sheet ตามคลิป: avatar กลาง + "Block <user>?" +
  "This will also block any other profiles they may have or create in
  the future. You can unblock them anytime." + impact 2 แถวพร้อมไอคอน
  (ข้อความ/กระดิ่งขีดฆ่า) + ปุ่ม Block แดง + "Block and report"

เคส 3: Block มีผลจริงใน session — ผ่าน (automated)
  กดยืนยัน → toast "Blocking" (ตามคลิป) → state PF_BLOCKED + flag
  p.blocked บนโพสต์ทั้งหมดของ seller; unfollow อัตโนมัติผ่าน pfSetFollow
  (เคลียร์ favorite/mute ด้วยตาม logic เดิม); เข้าลิสต์ PF_REMOVED_FOL
  → หลุดจาก own followers; โพสต์หายจาก feed + search (เพิ่ม !p.blocked
  ที่จุดกรองเดิมของ ni/muted + resultSellers); โปรไฟล์ยังเปิดได้ตาม
  คลิป — ปุ่ม Follow กลายเป็น "Unblock" แดง, Message อยู่ครบ, grid
  โชว์ปกติ; Posts viewer head ไม่โชว์ Follow pill เมื่อ blocked

เคส 4: Unblock — ผ่าน (automated)
  ทางเข้า 3 จุด: ปุ่ม Unblock บนโปรไฟล์, แถว Unblock ในเมนู ..., ปุ่ม
  Unblock ใน Settings > Blocked profiles — ทั้งหมดเปิด center dialog
  เดียวกัน "Unblock <user>?" + desc "<user> and other profiles they may
  have or create will now be able to request to follow and message you
  on TukDaeng. They won't be notified that you unblocked them." +
  Unblock(แดง)/Cancel ตามคลิป; กดยืนยัน → Follow กลับ + banner ล่าง
  "You can restrict them to hide their comments and messages without
  blocking them completely. Learn more" (auto-dismiss 6s/แตะปิด);
  unblock ไม่ re-follow ตาม IG

เคส 5: Block and report — ผ่าน (automated)
  กด Block and report → block ก่อนแล้ว push ไปหน้า Report picker ตาม IG

เคส 5b: Report picker ตาม IG — ผ่าน (automated)
  กด Report (หรือ Block and report) → หน้าคั่น "What do you want to
  report?" + ตัวเลือก 2 แถว (A specific post / Something about this
  account) — ผู้ใช้ตัด "Recent messages they sent you" ออกเพราะ
  TukDaeng มีแค่ chat pop-up เล็กบนหน้าโพสต์ ไม่มีห้องแชทจริงให้เลือก
  ข้อความ (IG มี แอปเราไม่มี) → "Something about this account" ไป
  หน้าเหตุผล 9 ข้อเดิม, "A specific post" เปิด grid เลือกโพสต์ของเขา
  → เหตุผลโพสต์; X ปิด pop ทีละชั้นกลับโปรไฟล์

เคส 5c: Report thanks page ตาม IG (คลิป 813752856.187328.mp4 +
  ภาพรีวิวล่าสุด) — ผ่าน (automated)
  เลือกเหตุผล → หน้า "Thanks for your feedback": วงกลมเช็ค + "We use
  these reports to show you less of this kind of content in the
  future." + "Other steps you can take" — ปรับให้เข้า TukDaeng เหลือ
  action ที่มีจริง 3 แบบ:
  - Block <u> → sheet variant ตามภาพ: desc ตัดประโยค unblock ออก +
    impact 3 แถว (prohibit/bell/gear — "You can unblock them anytime
    in Settings.") + ปุ่ม Block เดียว (ไม่มี Block and report เพราะ
    อยู่ใน report flow แล้ว); block แล้ว row กลายเป็น Unblock → dialog เดิม
  - Unfollow <u> → ทำทันที + toast "Unfollowed" + row ค้างไว้พร้อม
    เครื่องหมายถูกเขียวตามภาพที่ 3 (โชว์แถวเฉพาะตอน following)
  - Mute <u> → center dialog "Mute <u>?" ตามภาพที่ 2: "Mute posts" /
    "Mute posts and story" / Cancel → toast "Muted" + เครื่องหมายถูกเขียว
  ตัด Restrict + Recent messages + Learn more (Community Standards)
  ที่ IG มีเพราะแอปเราไม่มีฟีเจอร์เหล่านั้น; ปุ่ม Done แดงปิดทั้ง stack
  + toast "Report submitted · thanks for letting us know"

เคส 6: Settings > Blocked profiles — ผ่าน (automated)
  เพิ่ม row "Blocked" (ไอคอน person-minus) ในส่วน What you see หลัง

เคส 7: About this account — ผ่าน (automated)
