1. Add Asset มีฟิลด์ ราคาซื้อ + วันที่ซื้อ — PASS

   - วันที่ซื้ออนาคตถูกบล็อก validation

2. Mark as Sold จาก asset detail — PASS
   - ฟอร์มมีเฉพาะ ราคาขาย + วันที่ขาย (ตัดฟิลด์อื่นออกตามรีวิว)
   - ราคาขาย required, วันที่ขาย required + ห้ามอนาคต, prefill จาก asking price
   - กดบันทึก → asset หลุด PF_ASSETS เข้า PF_SOLD, โพสต์เปลี่ยน pfkind=sold, ไปแท็บ "ขายแล้ว", หลุดฟีดและยอดรวม

3. Mark as Sold จากเมนู ... ของโพสต์ตัวเอง — PASS

   - โพสต์ธรรมดา (ไม่ผูก asset) ไม่มีเมนูนี้ — ต้องผูก asset ก่อน

4. สถานะขายแล้วเป็น final — PASS

   - เปิดหน้า Sold detail: ราคาขายเด่น + กำไร/ขาดทุนจริง + วันที่ขาย + ราคาซื้อ + ระยะเวลาถือครอง
   - ฟอร์ม/record แสดงเฉพาะฟิลด์ที่ระบบเก็บจริง (ตัด buyer/contact/pay/attach ที่ mock เกินออก)
